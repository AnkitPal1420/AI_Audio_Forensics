# Dataset directory

Place lawfully obtained, appropriately licensed audio files in `real/` and
`fake/` after reviewing the source dataset's terms and documenting its
provenance. These directories are intentionally empty in the starter project.

Keep original files unchanged where possible. Record source, license, collection
date, labels, and any transformations in a separate dataset manifest before
using audio in research. Do not commit recordings to version control.

Dataset labels are research annotations, not proof of authenticity or evidence
of criminal activity. Validate label definitions and limitations before drawing
conclusions.
